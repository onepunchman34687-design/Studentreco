PORTABLE ATTENDANCE APP
=======================
Double-click start_attendance.bat to run the app.
This launcher uses .\python\python.exe from this folder, not system Python.
Model files are stored under .\insightface_data.
Attendance database, captures, and app outputs are stored in this folder.
Use only on compatible 64-bit Windows PCs. Camera access and Windows native
runtime requirements can still vary by computer. Keep student biometric data secure.
